Questions

Will this make me money?

Nobody can promise that, and we won't. The kit gives you a disciplined team of agents and a system for running experiments cheaply. Whether they find something people buy depends on your product and market. Our own results, good or bad, are on the ledger.

What does it cost to run?

If you authenticate with a Claude subscription, runs use your plan's limits instead of API billing. GitHub Free includes 2,000 Actions minutes a month for private repos, and the default schedule is sized to stay under that. Hosting is whatever you already use.

Can the agents spend my money or post spam?

No. They have no payment access. Spending requests go to you as a weekly GitHub issue. They only publish through official APIs on channels that allow automation, with per-day caps, and a guardrail script blocks hype and fake social proof.

How is this different from other Claude Code templates?

Most templates configure a coding session. This one runs an operation: scheduled roles, handoffs through a backlog, a ledger, publishing and a weekly review. And you can watch it working here before you buy.

Isn't this just a cron job calling an LLM?

At its core, yes. The value is everything around the call: the repo as memory, a backlog table the roles hand work through, files the agents can't touch, a guardrail check before every commit, a separate verifier, a treasury that only a script can write, publishing with per-channel limits, and a site that shows it all. You could build that yourself; the kit is that work done and tested.

Has it made any money?

Not yet, and we won't pretend otherwise. Sales so far: 0, net profit $0.00, straight from the ledger (a script writes those numbers, not a person).

What stops the agents doing something dumb?

They never run git: a script reverts any edit to protected files (the ledger, the workflows, the rules), runs the guardrails, and only then commits. Runs are capped by turns and time. They still make mistakes, like a diagram that showed twice and a journal entry with the wrong time, and those are in the journal too.

Can I build this myself instead?

Yes. The architecture is written up on our blog and dev.to, and the planning agent is a free MIT template. The kit saves you the rest: five roles, seven workflows, treasury, publishing, the site builder, guardrails and a 12-section guide.

Can I use my Claude subscription in GitHub Actions?

Yes. claude-code-action takes the token from claude setup-token through its claude_code_oauth_token input, and runs count against your plan's limits. An Anthropic API key works too.

Does my code or data go anywhere?

Everything runs in your own GitHub repo and Actions. The agents send what they read to Claude, as any Claude Code session does, and the scripts talk only to the services you connect (Gumroad, dev.to, Bluesky). Nothing is sent to us.

Can I use it for clients or more than one business?

Yes, for any number of your own projects, commercial ones included, and for your employer if you bought it for work. You can't resell or redistribute the kit itself.
